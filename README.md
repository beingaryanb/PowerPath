# ⚡ PowerPath – Smart Electricity Load Balancer

**An Advanced Data Structures and Algorithms based electricity load management system built using C++17.**

## 📌 About the Project

PowerPath is a Smart Electricity Load Balancer designed to manage and allocate electricity efficiently across multiple rooms in a building.

It uses Advanced Data Structures and Algorithms to prioritize electricity demands, manage power allocation, represent building connectivity, and organize restoration requests.

## 🚀 Key Features

- Smart electricity load allocation
- Priority-based load management using Min Heap
- BFS and DFS graph traversal
- Room management using Hash Maps
- Tree-based hostel structure
- Restoration request management using Linked Lists and Queues
- Merge Sort for room consumption
- Knapsack-based power optimization

## 🛠️ Technologies Used

- C++17
- CMake
- HTML
- CSS
- JavaScript
- Advanced Data Structures and Algorithms

## 🧠 Data Structures and Algorithms

| Data Structure / Algorithm | Purpose |
|---|---|
| Min Heap | Priority-based load allocation |
| Linked List Queue | Restoration requests |
| Graph | Building connectivity and traversal |
| Tree | Hostel hierarchy |
| Hash Map | Room management |
| Merge Sort | Sorting room consumption |
| Greedy Algorithm | Electricity allocation |
| 0/1 Knapsack | Power optimization |
